# Free WiFi · Riverside Adventist Church

A small, responsive landing page created as a friendly nod to the Hispanic group of the Seventh-day Adventist Church in Riverside, Missouri.

## About this project

We did **not** create the original concept or claim credit for it. We first found the idea at [wifi-free.vercel.app](https://wifi-free.vercel.app/) and thought it was a clever and meaningful visual wink for the church community.

This repository is an independent adaptation that adds direct links to the church website and its social channels. Credit for the original concept belongs to its original creator. If you know who created the source project, please open an issue so the attribution can be made more specific.

## Sobre este proyecto

**No creamos el concepto original ni reclamamos crédito por su creación.** Encontramos originalmente la idea en [wifi-free.vercel.app](https://wifi-free.vercel.app/) y nos pareció un guiño visual interesante y significativo para la comunidad de la iglesia.

Este repositorio es una adaptación independiente que agrega enlaces directos al sitio web de la iglesia y a sus redes sociales. El crédito por el concepto original pertenece a su creador. Si conoces a la persona que creó el proyecto original, puedes abrir un issue para mejorar la atribución.

## Features / Características

- Responsive layout for phones, tablets, and desktop screens.
- Automatic language selection: English when the browser's primary language is English; Spanish otherwise.
- Accessible labels and translated alternative text.
- Direct links to the church website, YouTube, Facebook, and Instagram.
